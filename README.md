# Precipitadores electrostáticos de alambre y placas

Presentación interactiva (HTML) del artículo *"Simulación numérica y evaluación analítica de la eficiencia de recolección de partículas en un gas mediante precipitadores electrostáticos de alambre y placas"* (Kılıç, Mutlu & Altun, Applied Sciences, 2022).

## Ver

Abrir `index.html` con un servidor local (por ejemplo `python -m http.server`) o publicar con Cloudflare Pages conectado a este repo.

## Controles

- `→` / `Espacio` / clic en `›`: avanzar · `←`: retroceder
- `F`: pantalla completa
- Clic en una figura: ampliarla

## Editar integrantes

En `index.html`, sección `01 PORTADA`, bloque `<!-- Integrantes -->`.
